# Active project contract

Before changing this repository or starting any paid inference, read
`docs/active_router_protocol.md` and the machine-readable lock at
`artifacts/active_router_protocol.json`, plus every active amendment listed
there.

The active objective is to produce both:

1. a reproducible, classifier-centered model-routing study; and
2. a provider-neutral open-source router that users can train on any model
   pool for which they can supply model cards and evaluation outcomes.

The active incremental Tinker ceiling for Amendment 009 is USD 3,000.00. It is
a hard ceiling, not a spending target, and is separate from the completed
USD 220.00 program recorded by Amendments 001--008. Paid work must follow the
ordered stages and gates in the active protocol. Do not spend unused reserves
merely because they are available.

Amendment 010 replaces all-at-once Docker image preflight for the Amendment
009 development and held-out matrices with a frozen, resume-safe per-task
block lifecycle. Run every treatment for a task before removing only that
task's exact image.

Amendment 011 completed and failed. Kimi K2.6 128K resolved 4/12 frozen
development tasks versus fixed Qwen medium's 6/12 and added no unique solve.
Its precommitted decision stops further Tinker strong-candidate search. Do not
begin another paid Tinker model qualification or a new development matrix.
A future external-provider or newer-benchmark study requires explicit user
direction and a prospective versioned protocol.

Amendment 012 preserves that formal-submission result and gate decision but
corrects its interpretation. Two no-submission Kimi trajectories contained
complete tracked diffs that both pass the official grader, so the separately
labeled terminal-workspace diagnostic is Kimi 6/12 versus Qwen 6/12 with the
same solve set. Future ephemeral repository runners must capture the tracked
terminal workspace diff before cleanup and store it separately from the
explicit submission. Do not claim that Amendment 011 proved Kimi less capable
on this cohort; it failed the precommitted quality-cost admission gate.

Amendment 013 changes the repository license from Apache-2.0 to MIT at the
copyright holder's direction. It changes no study design or result.

Do not silently change models, task splits, caps, metrics, gates, or classifier
selection rules. A change is allowed only for an infrastructure defect, model
retirement, invalid treatment, or explicit user direction. Record the reason,
create a versioned protocol amendment, recompute the lock hash, and do so
before collecting outcomes under the changed design. Never make a
result-contingent protocol change after opening held-out grades.

Held-out task IDs must be frozen before held-out inference. No held-out labels,
gold patches, grader tests, or grader logs may be used for training, model
selection, threshold tuning, or debugging. Run all frozen held-out treatments
before opening their official grades.

Credentials belong only in environment variables. Never write, print,
serialize, commit, or forward them into task containers.
